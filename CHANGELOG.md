# Changelog
## [1.0.0] - 2026-08-21
### Added
- First public release of Krait, the Kryon IDE: visual screen editing, source editor, live preview, inspector and problems tooling in one studio.
- The studio bottom panel now has a full built-in terminal (Kapsule tab): a real shell with colors, scrollback, text selection, copy/paste, clickable links, mouse support and resizable panes, based on the Kapsule terminal emulator.
- A new Output tab next to the terminal shows project build output with copy and clear actions.
- The Tools menu opens the terminal (Ctrl+`) and the Output panel directly.
- Linux builds are now published as a portable AppImage and a tarball with checksums on GitHub Releases.
- The version is shown in the window title and reported by `krait --version`.
